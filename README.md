# Next Schoolwear Quickshop

A standalone prototype of the schoolwear product listing page. It includes the guided Quickshop tray, the in-place selection summary, standard and Quick Buy tile modes, and the Add to Bag tray with school essentials. Related schoolwear appears after the last matching product when Quickshop is active.

## Preview locally

Open `index.html` in a browser. The page includes its styles, scripts, fonts and images. The product listings, bag and checkout are simulated. The related category links lead to Next.

To try the main journey, select **Schoolwear Quickshop → Try the example choices → Find my uniform**. Choose **Quick Buy tiles** and select **Add to Bag** on a product to see the confirmation tray.

## Publish on GitHub Pages

1. Extract the ZIP and upload `index.html` and `README.md` to the root of your GitHub repository. In the browser, use **Add file → Upload files**, then commit the files to the branch you intend to publish.
2. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the branch containing `index.html` (typically `main`) and **/ (root)**, then select **Save**.
4. When the deployment finishes, open **Visit site** in **Settings → Pages**.
